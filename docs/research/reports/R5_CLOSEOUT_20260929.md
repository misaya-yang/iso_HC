# R5 分段伴随残差诊断：收尾分析

日期：2026-09-29。Status: verification receipt。当前决定由 [研究入口](../README.md) 管理，事实由 [evidence](../evidence.md) 管理。本报告记录用户要求停止后的理论、实验和执行结果，不是继续训练的指令。

## 结论与停止决定

**本轮没有显示 phase-adjoint 超过简单 gain 的质量—成本价值，停止推进，不追加训练、不扩规模。** phase在两个同学习率前缀中都比gain差，且更慢。数学构造成立，不能补足这个缺口。代码、证明、数据身份与原始日志作为研究资产保留；R4只作参考，RDM不恢复。

这是明确的开发投入决定。它不声称成熟LM已被证明失败，也不否定全部多流方法；本轮未完成原定268M-token主预算、独立seed或现代主干确认。这些未完成项不是继续投入的默认理由。

## 理论为何不足以救回方法

1. **打开历史梯度成立，却不是收益定理。** 零入口、阶段内单位tied读写和一次固定交汇保留精确baseline；pre writer导数为 \(\langle g_{boundary},\delta_j\rangle\)。但gain同样有非零初始学习信号，并在实际前缀中更好。
2. **内部交汇不是必要操作。** 只在出口做 \((h,m)\leftarrow(h+m,m-h)\)，也能让全部body writer获得 \(\langle g_{out},\delta_j\rangle\)。因此不能从信用分配证明推出内部phase必要；gated boundary skip也能匹配初始history梯度。
3. **局部几何不控制任务最优。** 固定地址、同读取/分支/单位自作用时的无剪切条件数合同成立。它不包含动态路由导数、整网乘积或不同gain的比较。unit绑定还限制primary增益；这可能是优化差异的来源之一，当前没有排他因果证明。
4. **维度刻画是设计边界。** 正尺度、无transport、全部历史源、串行精确初始化条件下，参考地址Gram秩等于不同尺度数且不超过流数。它是经典Gram/AR分解的特化，不是任务记忆容量下界，不支持直接扩成三流；近似核和并列reader已有反例。
5. **先行性压力没有解除。** HC与公开project/lift代码已覆盖一般多流读写。当前的绑定、互逆尺度和初始化合同有具体区别，但缺少强替代之外的收益时，不能靠区别凑成主会贡献。[最近邻核查](../literature.md)

另外，pre-shear在零点与angle写入同一创新，初始梯度重复；独立Adam参数的相同LR可能叠加更大的有效写入步长。未来不能把这个比较当成只改变几何。本轮shear没有质量结果。

完整证明及限制见 [theory §11](../theory.md)；12项初始代数和27项参考秩检查没有被pilot推翻，但它们不再支持当前方法优先级。

## 数值核验与执行问题

旧默认编译流程的一次更新预检中，baseline/phase评价曾出现约0.005 nat差异。四模式CUDA核验发现评价路径漂移；训练显式casts emulation、backward autocast off，持出评价统一raw eager后，对应差降至约5.16e-6。旧差异不作收益证据，也不声称所有成因已被逐项隔离。[CUDA回执](../../../results/phase_adjoint_20260929/cuda_initialization.json)

独立审查还发现调度器恢复时重选LR误复用旧primary，以及child退出未确认后继续调度的两处漏洞；launch前修复并复核。启动七臂长协议之前这些核验有价值，但整体流程仍过重。

**本轮的过程问题是廉价否证跑得偏晚。** 在没有超出gain的信号前，投入了过多理论扩展、比较臂、profile系列和通用执行/分析工具，并过早准备完整七臂长轨迹。工程正确是必要条件，不能替代对idea的快速筛选。

以后按用户要求收敛：先写出新增操作必须超过的最小替代，先做baseline/gain/候选的短配对诊断及必要精度/吞吐检查；若廉价替代在质量和成本上覆盖候选，默认停止该idea，而不是用尚未验证的长训练或更大状态延续叙事。只有差距明确、有可检验机制解释时再增加关键消融、训练长度和独立确认。
